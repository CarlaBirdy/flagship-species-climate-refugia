# Every fraction of a degree matters: Quantifying why 1.5° degrees should be our climate target for flagship Australian species

Companion repository for the analysis for "_Wildlife of the Brink: The Need for Strong Climate Action_" which was published as a report for the WWF-Australia and Deakin University on 10 Dec 2024: (https://wwf.org.au/news/2024/2-c-of-warming-could-wipe-out-rare-australian-bird). This analysis was led by Dr Carla Archibald and assisted by Prof Brett Bryan and Dr Kita Ashman.

This repository also contains additional analyses for the paper "_Every fraction of a degree matters: Quantifying why 1.5° degrees should be our climate target for flagship Australian species_" which has been submitted to a scientific journal for publication. 

The source data for the climate scenarios can be found on the WorldClim website here: https://www.worldclim.org/. The source data for the species data can be found on the Atlas of Living Australia website here: https://www.ala.org.au/. The species habitat models will also be hosted open open-access GigaDB, found here: 

Archibald CL; Summers DM; Graham EM; Bryan BA. Supporting data for "Habitat suitability maps for Australian flora and fauna under CMIP6 climate scenarios" GigaScience Database 2023. http://dx.doi.org/10.5524/102491

This repository contains all code and documentation which was used to produce the:
1. Code to pre-process climate data and species data
2. Code to process the MaxEnt analysis
3. Figures
